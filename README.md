# bash-scripts

A collection of Bash scripts for common systems administration tasks.

## Scripts

- **backup.sh** — automates backup routines
- **bulk_server_check.sh** — checks status across multiple servers at once
- **disk_checker.sh** — monitors disk space usage
- **failed_login_monitor.sh** — tracks failed login attempts
- **file_organizer.sh** — organizes files systematically
- **log_parser.sh** — parses log files
- **log_rotation.sh** — manages log file rotation
- **menu.sh** — interactive menu for running the other scripts
- **server_health.sh** — monitors overall server health status
- **server_report_emailer.sh** — sends server status reports via email
- **service_monitor.sh** — tracks service status
- **system_info.sh** — displays system information
- **user_checker.sh** — monitors user accounts
